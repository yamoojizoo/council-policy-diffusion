# data/

국회도서관 「광역 지방의회 회의록 데이터셋」 JSON 파일을 이 폴더에 둡니다(제출물에는 포함하지 않음: 약 2.7GB, 주최 측 제공 데이터).

```
data/
├── 2024_광역 회의록/2024_서울특별시의회.json
├── ...
└── 2025_광역 회의록/2025_충청북도의회.json      (총 36개 파일, 하위 폴더 구조는 자유)
```

- 읽는 형식: `.json`(배열 또는 객체), `.json.gz`, `.jsonl`
- 사용하는 필드: `RASMBLY_NM`(의회명), `MTGNM`(회의명), `MINTS_NM`(회의록명), `MTG_DE`(회의일자), `MINTS_HTML`(본문 HTML)
- 확인용: 제출 결과를 만든 데이터는 회의록 원본 10,263건 → 중복 제거 후 9,886건, 발언 3,114,437개입니다. 실행 로그의 첫 줄들이 이 숫자와 같으면 같은 데이터입니다.
- 데이터 없이 동작을 확인하려면 합성 회의록을 쓰세요: `python tests/make_synthetic.py data_synth`
